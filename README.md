# 🎙️ TF Music — ভোকাল স্টুডিও

গান রেকর্ড, মিউজিক ম্যাচিং ও মাস্টারিং করার নিজস্ব স্টুডিও। মোবাইল ও কম্পিউটার দুটোতেই চলে, ইনস্টল করে অ্যাপের মতো ব্যবহার করা যায়, ইন্টারনেট ছাড়াও চলে।

**অ্যাপ খুলুন:** https://taiful666.github.io/TFMUSIC/

## মোবাইলে ইনস্টল করবেন যেভাবে
- **Android (Chrome):** লিংকটা খুলুন → ওপরের "📲 ইনস্টল" বাটন চাপুন (অথবা ⋮ মেনু → *Install app*)।
- **iPhone (Safari):** লিংকটা খুলুন → নিচের Share (⬆️) বাটন → *Add to Home Screen*।

> ⚠️ লিংকে **TFMUSIC** অবশ্যই বড় হাতের অক্ষরে লিখতে হবে। Facebook/Messenger-এর ভেতরের ব্রাউজার বা ডাউনলোড করা ফাইল থেকে ইনস্টল হয় না — Chrome-এ খুলুন।

## নতুন
- 🎤 বড় স্টেজ — লিরিক্স নিচ থেকে ওপরে ওঠে (মাউস হুইলে সামনে-পেছনে), অথবা লিরিক্স ভিডিও মাঝখানে টাইমলাইনের সাথে বাজে
- 🎚 যত খুশি ভোকাল ও মিউজিক ট্র্যাক — প্রতিটিতে আপলোড, M / S / ভলিউম; ক্লিপ টেনে যেকোনো ট্র্যাকে
- 🎧 গাইড ট্র্যাক (G) — আসল গান হেডফোনে শুনে গান, ফাইনাল গানে যায় না
- 🌧 শ্রাবণের মেঘ — পুরো গান তাল ধরে একটু পরে পেছনে আবার বাজে (½ / ১ / ২ / ৪ তাল), পুরো গানে / লাইনের শেষে / বাছাই অংশে
- ✨ মাস্টার মিক্স — কণ্ঠ মিউজিকের ভেতরে বসে: গাওয়ার সময় মিউজিকে জায়গা, লেভেল ও গলার টোন মেলানো, ডি-এসার, ডাউনলোডে স্ট্রিমিং লাউডনেস
- ↺ প্রতিটি ইফেক্টের রিসেট; সেটিং বন্ধ করে খুললেও থাকে
- ⌨️ Space = প্লে / পজ

## যা যা করা যায়
- মিউজিক বাজিয়ে তার সাথে গান রেকর্ড, ভুল অংশ আবার রেকর্ড (পাঞ্চ-ইন)
- 🎯 সুর সংশোধন (বেসুরো অংশ ঠিক করে), 🤖 রোবটিক অটো-টিউন, 🎶 হারমোনি কণ্ঠ — গানের কী নিজে শনাক্ত করে
- ✨ কণ্ঠ মসৃণ, 🌊 কোরাস, 🔥 অ্যানালগ উষ্ণতা, 📻 রেডিও — একসাথে একাধিক ইফেক্ট, প্রতিটির আলাদা মাত্রা
- ৮টি প্রফেশনাল প্রিসেট (গান, গজল/নাশিদ, ওয়াজ, আবৃত্তি, পডকাস্ট) — একাধিক প্রিসেট একসাথে মেশানো যায়, প্রতিটির আলাদা মাত্রা
- 📱 মোবাইলে মধুর শোনানো — ফোনের ছোট স্পিকারেও গান ভরাট ও মিষ্টি শোনায়, সাথে ফোন-স্পিকার প্রিভিউ
- নয়েজ রিমুভার, অটো লেভেল, অটো ডাকিং, ইকো, রিভার্ব, EQ, কম্প্রেসর
- কাটা, জোড়া, সরানো, আনডু/রিডু, লুপ প্র্যাকটিস — মোবাইলের জন্য আলাদা বড় বাটনের এডিট প্যানেল
- ফাইনাল মিক্স বা শুধু ভোকাল WAV ডাউনলোড

- 📱 ফোনে অ্যাপের মতো ডিজাইন — ওপরে টাইমলাইন, নিচে ট্যাব (রেকর্ড • এডিট • প্রিসেট • ইফেক্ট • মিক্স), লম্বা স্ক্রল নেই
- 🎤 লাইভ মোড — ফোনকে ইফেক্টসহ মাইক বানিয়ে অনুষ্ঠানে গান/বক্তব্য, ফিডব্যাক গার্ড, পুরো অনুষ্ঠান রেকর্ড
- ফোনের রেকর্ডার অ্যাপে গাওয়া গান আপলোড করলে রেকর্ডের মতোই বসে, পরিষ্কার ও লেভেল ঠিক হয়

> রেকর্ডের সময় হেডফোন ব্যবহার করুন।
